Zoom Chat
The Meeting Follow-Up bot in Zoom Team Chat — already shipped for the three base message types (New task detected, Completed, Need Clarification). This page adds Workflow's states and shows what ships next. Slack and Microsoft Teams reuse this same set of cases, re-expressed in each platform's own card syntax — see the note at the end.
Why this reads differently from email
Chat isn't static like email — the bot's buttons call back to a server, so Copy and jump-to-chat both actually work here, and a card can update itself in place after a click instead of going stale. That's why Copy, which email doesn't get, is back on every card below.
One hard constraint from the bot platforms: every actionable button must sit at the card's top level. There's no hidden menu, no nested layer, no nested "show more" behind which a button can live — show more/less may only hide text, never a button. Multiple recipients still split into separate messages, never one card with two blocks, same rule as email.

Next: Slack and MS Teams
Same cases, same copy, re-expressed in each platform's own card syntax (Block Kit for Slack, Adaptive Cards for Teams) by the bot team — not by us. Confirmed so far: buttons, Copy, and jump links work on both; inline pick-a-contact needs a Slack modal or a Teams Task Module (untested); live card updates are untested on both. Where a platform can't match a capability, it falls back to Copy + manual action rather than breaking.
